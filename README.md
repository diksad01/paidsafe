# PaidSafe

> Freelancer payment protection for Africa.

African freelancers deliver real work and never get paid — and right now, nothing stops it. PaidSafe creates a trust layer using milestone-based contracts, Flutterwave split payments, and an AI agent that generates structured contracts from plain English.

---

## The Problem

Freelancers across Nigeria, Kenya, Ethiopia, and the rest of Africa are ghosted after delivery every day. No contract. No escrow. No recourse. Existing tools like Fiverr take 20% and lock you to their platform. PaidSafe is built for the WhatsApp-native, mobile-first African freelance workflow.

---

## How It Works

1. Freelancer describes the job in plain English
2. AI agent generates a structured milestone contract
3. Client receives a link, agrees, and pays the first milestone
4. Funds are held until the freelancer marks delivery complete
5. Client approves — payment releases automatically (98% to freelancer, 2% platform fee)
